# VSTEP Listening — Work & Employment — Teacher

Phiên bản hoàn chỉnh cho GitHub Pages.

## Nội dung

- Warm-up True/False dùng toàn bộ 123 mục Vocabulary/Phrase từ file Word nguồn.
- Part 1: Questions 1–6.
- Part 2: Questions 7–14.
- Part 3: Questions 15–24.
- B2 Paraphrase Challenge nằm ở cuối từng Part; không có audio/script/evidence.
- Part 2 và Part 3: audio của từng bộ câu hỏi sticky theo bộ; khi mở Script, Question và Script có vùng cuộn riêng trên desktop.

## Đưa lên GitHub Pages

1. Tải toàn bộ file trong gói lên cùng một repository và giữ tất cả file ở thư mục gốc.
2. Vào **Settings → Pages**.
3. Chọn **Deploy from a branch**, chọn nhánh chứa các file và thư mục **/ (root)**.

Trang chính sử dụng `index.html`. Không đổi tên các file audio, hình ảnh, CSS hoặc JavaScript.

- Part 2–3: chỉ thanh audio của từng bộ câu hỏi ở trạng thái sticky; câu hỏi và Script cuộn tự nhiên theo trang, không có vùng cuộn riêng.

- Part 2–3: thanh audio sticky theo từng bộ câu hỏi; câu hỏi cuộn tự nhiên. Khi bật Script, khung Script sticky bên dưới thanh audio và có thể cuộn nội dung riêng khi cần.

## Warm-up

Warm-up uses all 123 vocabulary/phrase items from the supplied Word file. Each English item has four Vietnamese meanings; correct answers are randomized and balanced across A/B/C/D as evenly as mathematically possible (31/31/31/30).
